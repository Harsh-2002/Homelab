binary, verify, then prune old images and residual data.

## Not upgraded, and why

- **OpenViking v0.4.22** stays. v0.5.3 spans four breaking releases (0.5.0 to 0.5.3)
  including an external peer-identity change, removal of admin migration, and a
  reworked session-lock design. The stack also bind-mounts a local full-file
  hotfix (`session_commit_processor.py`) written against v0.4.22, which upstream
  v0.5.3 has refactored; that override must be dropped, not carried over.
  A staged test on a copy of the state (no Codex credential, no published ports,
  dummy VLM) showed v0.5.3 boots healthy, keeps all 9 peer directories, creates no
  `ext-*` directories, and answers semantic search with the same top hits.
  Not covered: the OpenCode plugin, Hermes provider and MCP clients against 0.5.3,
  and the commit queue under a real VLM. This is the memory backend for every
  agent, with no security fix pending, so it waits for an explicit go-ahead.
- **OpenCloud 7.2.4** stays. 7.2.4 is the latest stable on `opencloudeu/opencloud`.
  The GitHub release `v9.0.0` is published to the separate
  `opencloudeu/opencloud-rolling` image, a channel change rather than an upgrade.
  The LDAP credential rotation is still open.

## Rollback

- Stack compose files: the previous version of each changed stack is archived in
  `/BACKUP/preupgrade-20261107-2318/portainer-stack-files/`
  (`backup-<stack>-<timestamp>.yml`, root-only because they can contain literal
  secrets); paste one back and redeploy with `portainer/stack-update.py`.
- Caddy: `/BACKUP/preupgrade-20261107-2318/caddy.2.11.4.bin` back to
  `/data/apps/caddy/caddy`, then `docker restart caddy`.
- Data: Immich database dump, Pocket ID, tinyauth, AdGuard, Paperless
  (without media), Karakeep Meilisearch, Orva and Caddy data are archived in the
  same backup folder. Old images were pruned, so a rollback pulls the previous
  tag or digest again.

## Findings worth remembering

- Portainer redeploys continue after the API call returns, and a 9 GB pull (Ollama)
  takes minutes; confirm with `docker ps` before assuming it failed.
- The default Docker bridge is disabled, so one-off `docker run` needs
  `--network l3b`.
- Meilisearch 1.56 renamed the dumpless-upgrade variable to `MEILI_UPGRADE_DB`.
- Digest-pinned stacks (Caddy base, Pocket ID, AdGuard, Orva, OpenViking, Ollama,
  tinyauth, Unbound) are skipped by Watchtower by design; check them manually.
- The repo's Paperless compose was stale at 3.2.1 while 3.4.1 ran; now corrected.
