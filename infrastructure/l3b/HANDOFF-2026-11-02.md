## Firewall: one backend, compatible management

The host uses nftables through Debian's **iptables-nft** interface. Docker and
the WireGuard helper both use that interface. Legacy firewall rules were absent
when checked; standalone nftables.service was disabled. These installed command
packages are not separate running firewall daemons. Preserve the selected
backend; do not flush rules or migrate Docker during unrelated maintenance.

The root-owned helper manages only its dedicated L3B-WG chain and owned hook.
It permits intended VPN-to-LAN traffic and established replies, defers published
Docker-port decisions to Docker, and rejects other VPN forwarding. Docker's NAT
and FORWARD DROP remain. The Docker start hook reconciles VPN rules if wg0
exists; WireGuard has PostUp/PostDown hooks and boot ordering after Docker.
