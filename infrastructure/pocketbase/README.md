# PocketBase removed

PocketBase was completely removed at the owner's request on 2026-10-18. Its
container and data were on the retired Supabase VM108, which was destroyed along
with its owned disks, replication copy and VM backups. The Caddy handler and
Homepage card were removed. No PocketBase workload was created on Kubernetes.

The previous deployment files are available in Git history, not active state.
